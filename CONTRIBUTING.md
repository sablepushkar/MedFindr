# Contributing to MedFindr

This is a student project, and I am still learning how to structure and test it. Small, clear contributions are more useful than large rewrites.

If you want to suggest a change:

1. Explain the problem you noticed.
2. Keep the change focused.
3. Add or update a test when the behaviour can be tested.
4. Say what you ran locally and what did not work.
5. Do not include real patient information, API keys or other private data.

For rule changes, please include examples where the rule should match and where it should not. The current examples are limited, so a passing test does not prove that a rule is clinically correct.

I may not be able to review every contribution quickly, but clear reproduction steps help me understand it.
