# Signal and review code: current scope

The signal code adds structured context to the app's existing response flow. It uses a small set of phrase and context rules; it is not a clinical language model.

- utils/clinical_data.py extracts a limited amount of structured context from the text.
- utils/safety_signals.py checks configured medication-related patterns. A match does not prove that a medicine caused a symptom.
- utils/evidence.py records whether a note was generated by a rule or returned by a public lookup.
- utils/analysis_trace.py keeps an in-memory trace to help inspect the code path.
- utils/review.py validates review fields for the current session.
- utils/review_export.py writes a JSON export when requested.

The trace and review data are not stored in a permanent audit database. The phrase matching can miss context, including more complicated negation. The included tests check the behaviour we have written down; they do not prove medical correctness.
